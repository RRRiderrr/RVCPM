Самый простой способ использовать RVCPM — скачать **готовую сборку для Windows** из GitHub Releases.

<div align="center">

### [⬇ Скачать последнюю версию RVCPM](../../releases/latest)

</div>

1. Откройте раздел **Releases**.
2. Скачайте ZIP-архив с последней готовой сборкой для Windows.
3. Распакуйте его в любую папку.
4. Запустите `RVCPM.exe`.

Для обычного использования Visual Studio и самостоятельная сборка не нужны. RVCPM хранит свои настройки, пакеты плагинов, рабочую копию Vencord и служебные данные в `%LOCALAPPDATA%\RVCPM`.

> [!TIP]
> Автоматически создаваемые GitHub архивы **Source code.zip** и **Source code.tar.gz** — это исходный код, а не готовая программа. Скачивайте ZIP со сборкой RVCPM, прикреплённый к релизу в разделе **Assets**.

## Что такое RVCPM?

**RVCPM** превращает работу с кастомными плагинами Vencord в обычный удобный desktop-процесс.

Вместо того чтобы вручную клонировать Vencord, копировать файлы в `src/userplugins`, устанавливать подходящие версии Node/pnpm, пересобирать проект, выполнять inject и повторять всё это после каждого обновления, RVCPM делает весь этот процесс самостоятельно.

Перетащите плагин в окно программы, вставьте ссылку на GitHub, выберите нужные плагины — остальное менеджер сделает сам.

> [!NOTE]
> RVCPM — независимый проект и **не связан официально с Vencord или Discord и не поддерживается ими**.

## Быстрый старт

### 1. Скачайте и запустите RVCPM

Откройте [последний GitHub Release](../../releases/latest), скачайте **готовый ZIP из Assets**, распакуйте его и запустите:

```text
RVCPM.exe
```

Если вы хотите изменять сам RVCPM, смотрите раздел [Сборка из исходников](#сборка-из-исходников).

### 2. Добавьте плагины

Можно:

- перетаскивать файлы, папки или ZIP-архивы в окно;
- использовать кнопки **Files** / **Folder**;
- вставить ссылку на публичный GitHub-репозиторий;
- вставить GitHub-ссылку `/tree/...`;
- вставить прямую ссылку `/blob/...` на файл плагина.

Перед установкой RVCPM просканирует источник и покажет найденные Vencord-плагины.

### 3. Установите

Нажмите **Install**. RVCPM автоматически выполнит:

```text
Обновление / клонирование Vencord
        ↓
Проверка Node.js + Git
        ↓
Определение версии pnpm, требуемой текущим Vencord
        ↓
Восстановление управляемых userplugins
        ↓
Установка зависимостей
        ↓
Сборка Vencord
        ↓
Inject свежей кастомной сборки в Discord
```

Менеджер использует собственную рабочую копию Vencord, поэтому обычные пользовательские файлы не используются как рабочая папка сборки.

## Поддерживаемые источники плагинов

### Нативные структуры Vencord userplugin

Однофайловый плагин:

```text
myPlugin.ts
```

или:

```text
myPlugin.tsx
```

Плагин в папке:

```text
myPlugin/
├── index.ts
├── native.ts
├── styles.css
├── components/
└── ...
```

или:

```text
myPlugin/
├── index.tsx
└── ...
```

Точка входа должна содержать обычное определение Vencord-плагина, например:

```ts
export default definePlugin({
    name: "MyPlugin",
    description: "My custom plugin",
    authors: [...]
});
```

RVCPM также понимает сопутствующие файлы и ресурсы: дополнительные TypeScript/TSX-модули, `native.ts`, CSS, JSON и локальные assets.

### Форматы, которые RVCPM умеет импортировать

Они автоматически преобразуются в корректную структуру Vencord userplugin:

| Источник | Поддержка |
|---|:---:|
| `.ts` | ✅ |
| `.tsx` | ✅ |
| Папка плагина | ✅ |
| ZIP-архив | ✅ |
| Несколько ZIP одновременно | ✅ |
| Смешанные файлы + папки + ZIP | ✅ |
| Публичный GitHub-репозиторий | ✅ |
| GitHub `/tree/...` | ✅ |
| GitHub `/blob/...` | ✅ |
| Drag & Drop | ✅ |

Полные правила структуры находятся в [`SUPPORTED_PLUGINS.md`](SUPPORTED_PLUGINS.md).

## Суффиксы платформ Vencord

RVCPM распознаёт суффиксы Vencord, например:

```text
.dev
.web
.browser
.desktop
.discordDesktop
.vesktop
```

Обычный режим Discord Desktop принимает совместимые desktop-плагины и не позволяет случайно установить web/browser/Vesktop-only плагин. Dev-only плагины требуют соответствующую dev-сборку.

## Библиотека плагинов

У каждого управляемого плагина есть отдельная карточка с текущим состоянием и информацией об источнике.

Из библиотеки можно:

- включить или выключить плагин;
- открыть его настройки;
- посмотреть описание;
- посмотреть информацию из GitHub README, если она доступна;
- проверить обновление;
- обновить один плагин;
- удалить плагин;
- при необходимости удалить сохранённые настройки Vencord.

Если изменение требует перезапуска, RVCPM показывает баннер **Discord restart required** с кнопкой перезапуска Discord в один клик.

## Настройки плагинов

RVCPM умеет изменять обычные статически определяемые настройки Vencord без открытия Discord.

| Тип настройки Vencord | RVCPM |
|---|:---:|
| `STRING` | ✅ |
| `NUMBER` | ✅ |
| `BOOLEAN` | ✅ |
| `SELECT` | ✅ |
| `SLIDER` | ✅ |
| Простой статический `CUSTOM` | ⚠️ Частично |
| `BIGINT` | ➖ Только в Discord |
| `COMPONENT` | ➖ Только в Discord |
| Сложный динамический `CUSTOM` | ➖ Только в Discord |

`COMPONENT` — это произвольный React-интерфейс, который рендерится внутри Discord/Vencord, поэтому RVCPM намеренно не запускает его внутри собственного WebView2-интерфейса.

## Обновления

RVCPM сохраняет достаточно информации об источнике, чтобы позже обновлять плагины.

**GitHub-плагины** проверяются по исходному commit.  
**Локальные плагины** отслеживаются по SHA-256 исходных файлов.

Можно обновить один плагин или использовать **Update All**. Перед заменой рабочей версии RVCPM создаёт rollback-копию и подтверждает новое состояние только после успешной сборки Vencord и inject.

Во время установки или пересборки управляемых плагинов RVCPM также обновляет свою рабочую копию Vencord до актуальной ветки `main` перед компиляцией.

## Plugins+

Если существует хотя бы один плагин, управляемый RVCPM, во время сборки менеджер автоматически добавляет небольшой внутренний integration-userplugin.

Он меняет стандартный пункт Vencord Settings:

```text
Plugins
```

на:

```text
Plugins+
```

Меняется только название существующего раздела Vencord. Если RVCPM не управляет ни одним плагином, integration-plugin не добавляется.

## Локальные данные

RVCPM хранит данные, относящиеся к конкретному компьютеру, в:

```text
%LOCALAPPDATA%\RVCPM\
```

Типичная структура:

```text
RVCPM/
├── config/          # настройки менеджера
├── packages/        # snapshot-копии управляемых плагинов
├── repositories/    # рабочие копии GitHub / состояние источников
├── vencord/         # отдельная рабочая копия Vencord
├── logs/            # журналы операций
├── temp/            # временные файлы импорта/сборки
└── WebView2/        # данные профиля WebView2
```

Благодаря этому каждый компьютер независим: RVCPM не предполагает, что на другой машине используются те же пути, та же установка Discord или те же исходные файлы плагинов.

## Поддерживаемые версии Discord

RVCPM умеет работать с:

- Discord Stable;
- Discord PTB;
- Discord Canary;
- автоматическим определением;
- пользовательским путём к Discord.

## Требования

- Windows 10 или Windows 11;
- .NET Framework 4.7.2;
- Microsoft Edge WebView2 Runtime;
- подключение к интернету для обновлений Vencord/GitHub и первичной установки зависимостей;
- Git и совместимая с Vencord версия Node.js.

RVCPM проверяет инструменты сборки и при наличии `winget` умеет автоматически установить недостающие Git/Node. Требуемая версия pnpm читается непосредственно из **актуального `package.json` Vencord**, а не зашивается в код RVCPM.

## Безопасность

> [!WARNING]
> **Vencord-плагин — это исполняемый код, который запускается внутри Discord.**

RVCPM умеет проверять структуру исходника, безопасно распаковывать ZIP-архивы и не выполняет код плагина во время анализа импорта, однако он не может сделать потенциально опасный сторонний плагин безопасным.

Устанавливайте плагины только от разработчиков и из репозиториев, которым вы доверяете.

Для ZIP-импорта используется защита от path traversal и ограничения распаковки, чтобы снизить риск записи вредоносным архивом файлов за пределы временной рабочей папки RVCPM.

## Решение проблем

<details>
<summary><b>Плагин определяется через Files, но не через Drag & Drop</b></summary>
<br>
Убедитесь, что используете актуальную версию RVCPM. В текущих версиях Drag & Drop и обычный файловый диалог используют один и тот же механизм анализа ZIP/плагинов.
</details>

<details>
<summary><b>Программа сообщает, что Discord нужно перезапустить</b></summary>
<br>
Это нормально после изменения некоторых состояний или настроек плагинов. Используйте кнопку <b>Restart Discord</b> в RVCPM, чтобы отложенные изменения безопасно применились перед новым запуском Discord.
</details>

<details>
<summary><b>Сборка Vencord завершается ошибкой</b></summary>
<br>
Откройте страницу <b>Logs</b>. Кастомный плагин может сломать сборку Vencord, если его код устарел, содержит ошибку или несовместим с текущей версией Vencord/Discord. RVCPM сохраняет rollback-состояние до успешного завершения новой сборки.
</details>

<details>
<summary><b>Почему RVCPM не умеет редактировать вообще все настройки плагинов?</b></summary>
<br>
Некоторые настройки Vencord являются произвольными React-компонентами или динамическим кодом. Для их воспроизведения вне Discord пришлось бы выполнять код плагина внутри RVCPM, чего программа намеренно не делает.
</details>
